# Wayline

An illustrated, responsive VPN concept website built with React, TypeScript, Redux Toolkit and Vite. A fictional product showcase—not a functioning VPN.

[View website](https://dechen17714.github.io/wayline/)

Run locally: `npm ci --ignore-scripts` then `npm run dev`. Build: `npm run build`.

Pushes to `main` automatically deploy to GitHub Pages. Font licence: `public/fonts/manrope-OFL.txt`.
